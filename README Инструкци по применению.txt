1. Программа - модель ровера на поверхности.
На поверхности можно задать препятствия 3 видов: камни - полусферы, бревна - полуцилиндры и гауссианы - холмы, полученные с помощью нормального распределения. После чего на этой поверхности запускается ровер - машинка 3 на 3 пикселя, у которой есть параметры: просвет (если заезжаем туда, где просвет не позволяет, то застреваем) и два параметра для максимальных углов наклона (вперед-назад и вправо-влево), превысив которые ровер завалится и перевернется. Ровер может ездить по 8 направлениям (S, N, W, E, NW, NE, SE, SW) и проезжать из точки А в точку В, которые вводятся через консоль.


2. Вся работа контролируется с помощью 3 файлов и того, что вы вводите в консоль.
   1. Config.txt - конфигурационный файл, он есть в приложении. И дополнительно Config_sample.txt с полным описанием, за что отвечает каждая строка и как должны выглядеть входные данные.
   2. surf_config.txt - файл управления генерацией поверхности, он есть в приложении. И дополнительно surf_config_sample.txt с полным  описанием, за что отвечает каждая строка и как должны выглядеть входные данные.
   3. rover_config.txt - файл управления ровером, также с примером и описанием rover_config_sample.txt.


3. Дальнейшее управление происходит из консоли:
   1. Сначала программа спрашивает, хотим ли мы случайную генерацию или чтение карты из BMP файла (0 - генерация, 1 - чтение BMP)
      1. Если вы выбрали чтение из BMP, программа предложит инвертировать, сжать и сгладить изображение, все параметры данных действий описаны при вызове чтения(всего сглаживаний несколько видов, стандартное нужно для чтения сгенерированных данной программой поверхностей, обычное, сильное и очень сильное сжимают картинку в зависимости от ваших нужд)
   2. Далее просит ввести имя файла для записи карты в BMP и в базу данных(текстовый файл, который хранит все имена путей и карт database_routes.txt и database_fields.txt соответственно)
   3. Далее спрашивает, откуда ровер должен стартовать
   4. После чего спрашивает, куда ровер должен приехать
   5. После чего запрашивает имя файла, куда загружать проезд
4. В итоге получается набор файлов: Boundary log.txt - файл с обработкой наших команд, Control log.txt - файл с применением наших команд, GNUplot.txt - файл для гнуплот с точками поля(по столбцами x y z координаты всех точек поля), Rover.txt – файл для гнуплот с путем ровера(по столбцами x y z координаты всех точек по которым проехал ровер во время следования из точки А в точку В). Также bmp файл поля с названием, которое вы занесли в консоли и два файла “базы данных”: лог тех карт, на которых вы ездили и маршрутов на них. Также файлы с препятствиями, обнаруженными ровером, Gauss.txt, Stone.txt, Log.txt - их также можно загрузить в гнуплот и получить карту препятствий.
5. Чтобы иллюстрировать проезд в гнуплоте нужно ввести следующую команду:
6. Splot “GNUplot.txt” w l, “Rover.txt” w l, “Stone.txt” lw 7, “Log.txt” lw 7, “Gauss.txt” lw 7.
